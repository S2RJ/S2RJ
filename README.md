
## 📋 Quick Reference

### When to Use Each Test

| Scenario | Test to Use |
|----------|-------------|
| Compare sample mean to known value | One-sample t-test |
| Compare two independent groups | Independent t-test |
| Compare before/after measurements | Paired t-test |
| Compare 3+ groups | ANOVA |
| Test proportion | Proportion z-test |
| Test independence of categories | Chi-square test |
| Predict continuous outcome | Linear regression |
| Predict with multiple predictors | Multiple regression |
| Non-linear relationship | Polynomial regression |

### Common Distributions

| Distribution | Use Case | Parameters |
|--------------|----------|------------|
| Normal | Continuous, symmetric data | μ (mean), σ (std) |
| Binomial | Count successes in trials | n (trials), p (probability) |
| Poisson | Count rare events | λ (rate) |
| Exponential | Time between events | λ (rate) |
| Uniform | Equal probability | a (min), b (max) |

### Key Formulas

**Mean**: μ = Σx / n

**Variance**: σ² = Σ(x - μ)² / n

**Standard Deviation**: σ = √(variance)

**Z-score**: z = (x - μ) / σ

**Standard Error**: SE = σ / √n

**Confidence Interval**: x̄ ± (critical value × SE)

**Linear Regression**: Y = β₀ + β₁X + ε
